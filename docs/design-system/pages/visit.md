# Visit page

The Visit page follows the CTC inner-page blueprint and uses the homepage's warm editorial language without copying its homepage-only atmosphere.

## Structure

- Light hero with one bronze CTA and a floating Sunday information card.
- Sage first-visit essentials band.
- White directions and Sunday-expectations split.
- Cream mission band using an editorial row list.
- White, progressively disclosed beliefs section to keep the page approachable.
- Sage pastor profile using the existing registered church portrait.
- White next-steps and directions closing band.

## Responsive behavior

Two-column sections stack at 900px. Cards become single-column at phone width, touch targets remain at least 44px, and all entrance and hover motion is suppressed for `prefers-reduced-motion`.

## Content sources

Mission and belief language is adapted from the legacy Christ Tamil Church Mission and Beliefs pages. Pastor content uses the existing shared site data.
